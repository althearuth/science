# 🚀 Quick Start Guide

## Science Club Website - Gov. Felicisimo T. San Luis ISHS

### ⚡ Fastest Way to View the Website

1. **Navigate to the project folder**
   ```
   Open the "science-club-website" folder
   ```

2. **Open index.html**
   - Double-click `index.html` in your file explorer
   - OR right-click → Open with → Your browser (Chrome, Firefox, Edge)

3. **That's it!** 🎉 The website will open in your browser.

---

## 📱 Testing Mobile View (Responsive Design)

### In Google Chrome:
1. Press **F12** (or right-click → Inspect)
2. Click the **device toolbar icon** (or press **Ctrl+Shift+M**)
3. Select a device from the dropdown:
   - iPhone 12/13/14
   - Samsung Galaxy S20
   - iPad
   - Or set custom dimensions

### In Firefox:
1. Press **F12** → Click **Responsive Design Mode** icon
2. Or press **Ctrl+Shift+M**
3. Choose your device size

### Try These Views:
- **Desktop**: 1920x1080 (Full features)
- **Tablet**: 768x1024 (iPad view)
- **Mobile**: 375x812 (iPhone view)
- **Small Mobile**: 320x568 (iPhone SE)

## 🔧 Customization (Optional)

### Change Colors:
1. Open `css/styles.css`
2. Find the `:root` section at the top
3. Change these values:
   ```css
   --primary-color: #4F46E5;    /* Main brand color */
   --secondary-color: #06B6D4;  /* Accent color */
   ```

### Update School Name:
Search and replace "Gov. Felicisimo T. San Luis" with your school name in all HTML files.

### Add Real Images:
1. Place images in the `images/` folder
2. Update the `src` attributes in HTML files

## 🐛 Troubleshooting

**Problem**: CSS styles not loading
- **Solution**: Make sure all files are in the correct folder structure
- Check that `css/styles.css` path is correct

**Problem**: JavaScript not working
- **Solution**: Open browser console (F12) and check for errors
- Ensure `js/main.js` is loading properly

**Problem**: Mobile menu not appearing
- **Solution**: Resize your browser window to below 768px width
- Or use DevTools responsive mode

**Problem**: Forms not submitting
- **Solution**: This is normal! Forms currently log to console
- Open DevTools Console (F12 → Console tab) to see the data
